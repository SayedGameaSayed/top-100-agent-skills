كيف تستخدم مهارات الذكاء الاصطناعي؟

مهارة الذكاء الاصطناعي هي مجلد يحتوي على ملف تعليمات برمجية دقيقة يُدعى SKILL.md يوضح للموديل كيفية إنجاز مهمة متخصصة خطوة بخطوة. تمنح المهارة النموذج قدرات عملية فورية لا يتقنها افتراضيًا، مثل إنشاء مستندات Word منسقة أو استخراج البيانات من ملفات PDF المعقدة. بفضل هذا المعيار المفتوح، أصبحت المهارات إضافة قياسية تفهمها وتنفذها النماذج الحديثة بدقة وكفاءة.

الطريقة الأولى (العامة)

النسخ واللصق: تعمل مع أي شات وأي موديل فوراً

هذه هي الطريقة الشاملة التي لا تحتاج لأي إعدادات مسبقة وتعمل مع ChatGPT، Gemini، Claude، Copilot، أو أي أداة أخرى:

  1. اختر المهارة التي تريدها من الصفحة الرئيسية وافتح تفاصيلها.
  2. اضغط على زر «انسخ البرومبت الجاهز»؛ سينسخ نصاً إنجليزياً يحتوي على رابط المهارة وتوجيهاً للموديل بالرد عليك بالعربية.
  3. الصق النص في محادثتك مع الموديل، ثم اكتب طلبك بالعربية مباشرة وسينفذه بناءً على تعليمات المهارة.
  4. إذا كان الموديل غير متصل بالإنترنت لقراءة الرابط، يمكنك فتح المصدر ونسخ محتوى ملف SKILL.md ولصقه يدوياً.
الطريقة الثانية (المتقدمة)

الدعم الأصلي في بيئات التطوير وأدوات سطر الأوامر

تدعم العديد من أدوات سطر الأوامر ومحررات الأكواد (مثل Codex و Gemini CLI و Claude Code و Copilot و Cursor) قراءة مجلدات المهارات تلقائياً من مسارات محددة.

الدعم والمسارات بتختلف من أداة لأخرى وبتتغير، راجع التوثيق الرسمي للأداة في صفحة كل مهارة ضمن تبويبات «ضيفها لأداتك».

🛡️

قائمة المراجعة الأمنية قبل الاستخدام: إيه اللي تراجعه قبل ما تثبّت؟

المهارات في بيئات التطوير المستقلة (Autonomous Agents) تملك قدرة على تنفيذ أوامر برمجية وقراءة ملفات من جهازك. تجنّب تقييمات الأمان الوهمية (مثل درجات A-F الآلية) واتبع هذه الخطوات اليدوية الأربع للتحقق من أي مهارة:

1. فحص ملف SKILL.md

اقرأ التعليمات بعينيك. هل تحتوي على توجيهات غريبة لمحاولة قراءة ملفات حساسة (مثل .env أو مفاتيح SSH)، أو إرسال بياناتك إلى سيرفرات خارجية مجهولة (Data Exfiltration)؟

2. فحص مجلد الأكواد التنفيذية (scripts/)

إذا كانت المهارة تتضمن مجلد scripts/ به ملفات بايثون أو باش أو جافاسكريبت، فهذه أكواد تعمل بصلاحيات المستخدم. راجع كل سطر قبل تشغيل المهارة.

3. قيود الصلاحيات والشبكة

لا تمنح المهارة وصولاً غير مقيد إلى الإنترنت أو سطر الأوامر إن لم تكن مهمتها تتطلب ذلك صراحة. شغّل الأداة في وضع طلب التأكيد قبل تنفيذ أوامر النظام الحساسة.

4. موثوقية المستودع والمؤلف

تحقق دائماً من أن الرابط يشير إلى المستودع الرسمي للجهة المطورة (مثل Anthropic أو Microsoft أو مجتمعات موثوقة معروفة)، وتجنب الحسابات المنسوخة حديثاً (Typosquatting).

Comprehensive Usage Guide

How to Use AI Agent Skills

An AI agent skill is a structured directory containing a declarative SKILL.md specification that instructs frontier models how to execute specialized workflows step-by-step. Skills give models immediate capabilities they lack by default—such as generating formatted Word documents, analyzing complex spreadsheets, or conducting disciplined test-driven development.

Method 1 (Universal)

Copy & Paste: Works with Any Chat and Model Instantly

This is the universal method requiring zero setup, compatible with ChatGPT, Gemini, Claude, Copilot, or any other LLM chat:

  1. Select the skill you need from the home directory and open its detail page.
  2. Click the «Copy Ready Prompt» button; this copies an instruction containing the verified skill URL and instructions for your model.
  3. Paste into your chat session and type your request directly. The model will adhere strictly to the skill specification.
  4. If your model cannot access external URLs directly, open the GitHub source, copy the raw SKILL.md contents, and paste them manually into your chat.
Method 2 (Advanced)

Native CLI & IDE Integration

Many modern CLI agents and code editors (such as Codex, Gemini CLI, Claude Code, Copilot, and Cursor) natively discover skill directories from standardized workspace or user paths.

Supported paths vary across tools. Refer to official documentation on each skill detail page under the "Add to Your Tool" tabs.

🛡️

Security & Pre-Installation Checklist: What to review before adding a skill?

Agent skills operating in autonomous development environments possess capabilities to run terminal commands and access workspace files. Avoid superficial automated scorecards (such as arbitrary A-F badges) and perform these 4 manual verification steps before executing any third-party skill:

1. Inspect the SKILL.md File

Read through instructions carefully. Look out for unexpected requests attempting to read sensitive credentials (like .env or SSH keys) or transmit telemetry to unknown external servers.

2. Audit Executable Scripts (scripts/)

If the skill includes executable Python, Bash, or Node scripts, these run with user privileges. Audit every line before executing.

3. Privilege & Network Boundaries

Do not grant unrestricted shell or internet access unless explicitly required for the task. Keep tools in confirmation mode for destructive commands.

4. Author & Repository Authenticity

Always verify the repository URL points to an authoritative official organization (such as Anthropic, Microsoft, Vercel, or reputable maintainers) to avoid typosquatting forks.
